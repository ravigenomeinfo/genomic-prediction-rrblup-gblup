# Data

**All data in `data/simulated/` are simulated. They do not represent any real maize panel or real field trial.**

Generated by `R/01_generate_data.R` (seed in `config.R`).

| File | Content |
|---|---|
| `genotypes_raw.csv` | Lines x SNPs, coded -1/1 (homozygous inbred lines), ~2% missing (`NA`) |
| `phenotypes.csv` | Simulated grain yield (t/ha), one value per line |
| `marker_map.csv` | SNP, chromosome (1-10), position (bp, synthetic) |
| `truth_lines.csv` | Simulation ground truth: subpopulation and true breeding value per line |
| `truth_qtl.csv` | Simulation ground truth: causal SNPs and effects |

The `truth_*` files exist only because the data are simulated. They are used to
report accuracy against true breeding values and to highlight causal loci in
figures. They are never used for model fitting.

`data/processed/` holds intermediate R objects and is git-ignored.

## Using your own data
Replace `genotypes_raw.csv` (rows = lines, columns = SNPs, coded -1/0/1 with `NA`
for missing) and `phenotypes.csv` (`line_id`, `grain_yield_sim`) with your files,
keep the same column names, and remove the `truth_*` dependencies from scripts
03, 05 and 06 (`r_tbv`, true subpopulation labels, QTL highlighting).
Only share data you are permitted to share publicly.
